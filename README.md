# GroundBnB (Backend)

## Overview

GroundBnB is a backend application built with **Spring Boot** and **MySQL**, designed to manage property listings, customer accounts, reservations, and reviews. It exposes a set of RESTful APIs consumed by the frontend application.

👉 **Frontend Repository (Angular):**  
https://github.com/BVasquez07/GroundBNB_Client

---

## Tech Stack

* **Java 17+**
* **Spring Boot**
* **Spring Data JPA (Hibernate)**
* **Spring Security**
* **MySQL**
* **JWT (JSON Web Tokens)**
* **Maven**

---

## Related Repositories

This project is part of a full-stack application:

- **Backend (this repo):** Spring Boot API  
- **Frontend (Angular):** https://github.com/BVasquez07/GroundBNB_Client  

Make sure to clone and run both repositories to have the complete application.

---

## Features

* Customer registration and authentication
* Property listing management
* Reservation system with date validation
* Review system with rating constraints
* Secure API endpoints with JWT authentication
* Relational database design with foreign key constraints
